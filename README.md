# 🧮 Python GUI Calculator

A clean, lightweight, and user-friendly desktop calculator built with Python and **Tkinter**. This project demonstrates fundamental GUI programming concepts, grid layout management, event handling, and clean code practices (DRY principle).

## ✨ Features

* **Basic Arithmetic Operations:** Supports addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
* **Dynamic UI Generation:** Buttons are rendered dynamically using Python tuples and loops in a 4x4 grid layout.
* **Keyboard Support:** 
  * Type numbers and operators directly from your keyboard.
  * Press `Enter` (`<Return>`) to calculate the result.
  * Press `Esc` (`<Escape>`) to clear the display.
* **Error Handling:** Gracefully catches invalid mathematical expressions or division by zero (`ZeroDivisionError`) and displays an `"ERROR"` message without crashing.
* **Auto-Clear on Error:** Automatically resets the screen when typing a new number after an error state.

## 🛠️ Built With

* **Python 3.x**
* **Tkinter** (Python's standard GUI library — no external installations required!)
